# Skills - Keyring Router

## Project-owned
| Skill | When |
|---|---|
| `drizzle-orm` | Mandatory before a schema, migration or direct database operation after persistence tooling is selected. |

## Installed from environment (apply only when relevant, always customized)
| Skill | When |
|---|---|
| `spec-creation` | starting a new feature/fix that needs an SDD spec - creates the spec file and registers it in `features.md` |
| `frontend-design` | designing a landing page or local UI - visual direction, typography, avoiding templated defaults |
| `web-design-guidelines` | auditing UI code against Web Interface Guidelines before merging UI changes |
| `react-doctor` | only if a React frontend and its local scan command are introduced |


> Rule: never fork/copy-paste a skill without customizing it to Keyring Router (see `AGENTS.md`).

## Note
- The `.agents/skills/` folder holds adapted local skills and imported environment skills. A skill does not prove that its referenced tooling has already been selected.
